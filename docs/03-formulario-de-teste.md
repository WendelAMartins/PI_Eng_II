# Formulário de teste com usuários

Envie uma cópia para cada testador (mínimo 5). Peça print das telas com erro.

**Como acessar:** siga o README (`dotnet run`) ou use o endereço informado pelo autor.

## Roteiro sugerido

1. Abrir um chamado com todos os campos e uma foto JPG.
2. Tentar enviar o formulário vazio.
3. Tentar anexar um arquivo que não seja JPG ou PNG.
4. Abrir de novo o mesmo problema no mesmo endereço (deve avisar duplicidade).
5. No painel da chefia, aceitar o chamado e conferir o número da OS.
6. Programar uma data, iniciar e encerrar.
7. Consultar "Meus chamados" e conferir status e histórico.
8. Recusar um chamado sem motivo (deve bloquear) e depois com motivo.
